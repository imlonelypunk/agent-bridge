# Agent Bridge for Claude Desktop

Install the `.mcpb` through Claude Desktop's extension settings. Set the Python 3.10 or newer executable, shared mailbox directory, and Git workspace for attachments. Use the same channel directory as the Codex and Antigravity clients. Start a fresh Claude Code session to use the mailbox.

Ask Claude to send a text message, attach an explicitly approved tracked file, or read a reply from the mailbox. This profile allows explicit advisory dispatch. A dispatch uses a signed-in vendor CLI on the mailbox host and can send selected text and eligible snapshots to that provider.

Uninstall the extension to revoke its access. The shared mailbox remains on disk. See [data handling](PRIVACY.md) and the [MIT License](LICENSE).
