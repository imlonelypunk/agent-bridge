# Changelog

## 0.1.5

- Run the Windows scheduled Codex listener without a console and record its diagnostics to a local log.

## 0.1.4

- Add live inbox listening and repository-scoped Codex queue delivery, with crash-recoverable reservations.

## 0.1.3

- Bundle the bridge tool that returns correlated replies to a waiting agent session.

## 0.1.2

- Add opt-in automatic Antigravity request and reply delivery with mailbox claims to avoid duplicate submissions across windows.

## 0.1.1

- Generalize the IDE extension for Antigravity, Codex, and Claude Code roles.
- Add repository-scoped send, inbox, and reply routing for Git origins and configured cloud/local aliases.
- Bundle the Python bridge runtime in VSIX builds.
- Add documented Claude Code and Codex chat adapters with clipboard fallbacks.
